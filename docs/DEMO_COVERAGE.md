## Isolation and discovery

Vault demo uses `?demo=true` on the existing private Vault URL. The canonical remains `/snapshot-vault/`; that page remains noindex and absent from the sitemap. Exiting demo removes the query and remounts the real view, discarding demo selections/results. No fictional snapshot is passed to IndexedDB, save, backup, import or delete functions. The active export is unchanged. Demo remains usable when local storage is unavailable. Core-demo Dashboard links directly to fictional Vault history without displaying real saved records in that card.

The sample is rasterized from the repository's original synthetic portrait fixture (see `public/demo/README.md`). It uses exactly one allowlisted same-origin asset. Other local/arbitrary image URLs remain rejected by the enhancement helper. Public lookup still requires a verified Instagram/Facebook CDN URL. Sample mode emits no profile lookup analytics and displays no Instagram link; source loading needs no Instagram, Worker or remote image. AI runtime/model files load from this site only after explicit AI upscale, with the same production pipeline, progress, cancellation and native output dimensions. Exit sample returns to lookup without bypassing a lookup cooldown.

## Verification and limitations

Unit tests validate core counts/date coverage, all six chronological Vault pair comparisons and unchanged private-list share exclusions. Desktop/mobile Playwright covers every listed surface, demo link/CSV safety, real Vault preservation (including metadata), unavailable-storage demo, query canonical/sitemap behavior, sample network isolation and controls, actual native AI inference and saved PNG dimensions. Relevant WebKit mobile emulation checks the same flows; physical iPhone performance is not established by emulation. Browsers without fullscreen/WASM support show the existing honest failure state. Core export demo and Vault fictional history are separate examples, not one reconstructed historical account.

No production SEO URL, title, H1, canonical, parser, real-export missing-category semantics, or remote lookup infrastructure is changed.
